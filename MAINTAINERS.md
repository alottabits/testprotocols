# Maintainers

The people who may trigger a review (`/review`), merge, tag and cut a
release for this repository. The same handles are in `.github/CODEOWNERS`.
This file is the authorisation list the review workflow reads: a
`/review` comment counts only when the commenter's handle appears below.

One line per maintainer, in this exact form:

```markdown
- @handle — <scope>
```

## Maintainers

- @rjvisser — everything (`*`)

Adding a maintainer is a line here and a line in `.github/CODEOWNERS`;
the process in CONTRIBUTING.md does not change.
